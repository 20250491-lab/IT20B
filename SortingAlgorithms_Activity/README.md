Reflection Questions

1. How does each sorting algorithm arrange numbers? What makes their processes different?

Ang Bubble Sort kay mag-compare sa magtapad nga numbers, tapos kung mas dako ang left kaysa right, mag-swap sila. Sa Selection Sort, mangita siya sa pinakagamay nga number sa mga nabilin na numbers tas ibutang sa sakto nga position. angg sa Insertion Sort, kuhaon niya ang usa ka number then pangitaon kung asa siya dapat ibutang. Lahi-lahi ilang process pero same ra ilang goal, ang i arrange ang mga numbers sa kinagamyanan padung sa kinadak an.

2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?

Para sa akoa, Bubble Sort ang pinakasayon sabton ug buhaton kay simple ra iyang process. i compare ra niya ang duha ka magtapad nga numbers, tapo kung mas dako ang left value, mag-swap sila. Dali ra siya masabtan kay balik-balik ra ang pag compaare hangtod ma arrange tanan numbers.

3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.

Para sa akoa, Insertion Sort ang mas maayo kung sorted na daan ang numbers. dili na siya mag move ug numbers kung naa na sila sa sakto nga position.

4. What will happen if you add more numbers to your array? How might this affect the performance of each sorting algorithm?

Kung magdugang tag numbers sa array, mas daghan na ang kinahanglan i compare ug i arrange. mas mudugay ang process labi na kung daghan na kaayo ang numbers. Ang Bubble Sort ug Selection Sort mahimong mas dugay kay daghan silag comparisons, ang kay Insertion Sort mahimong mas paspas kung hapit na sorted ang numbers. so ang performance magdepende pud sa kadaghan ug arrangement sa numbers.

5. As a future programmer, why is it important to understand different sorting algorithms instead of using just one?

Importante nga makatuon ta ug different sorting algorithms kay dili tanan situations parehas. naay algorithm nga mas bagay sa certain nga type or arrangement sa data. kung kabalo ta sa ilang differences, mas dali ta makapili kung unsay mas angay gamiton. makatabang pud ni para makahimo tag programs nga mas efficient ug dili sayang sa processing time.
